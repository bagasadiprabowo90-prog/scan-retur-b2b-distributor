============================
SETUP CHECKLIST - SCAN RETUR
============================

1) apps-script/Code.js
   - Salin isi Code.js ke Apps Script editor
   - Jalankan fungsi 'setupEnvironment' (Run > setupEnvironment):
     * Menyimpan SPREADSHEET_ID ke Script Properties dengan aman
     * Membuat otomatis tab sheet 'Users' untuk whitelist email @blpbeauty.com
   - Tab retur (mis. "Bagas", "Dimas") <- nama sheet harus PERSIS sama

2) Deploy Apps Script sebagai Web App:
   - Klik Deploy > New deployment > Web App
   - Execute as: Me
   - Who has access: Anyone
   - Klik Deploy, copy URL yang muncul

3) Buat Google OAuth Client ID (untuk Google Sign-In @blpbeauty.com):
   - Buka console.cloud.google.com > APIs & Services > Credentials
   - Klik Create Credentials > OAuth client ID
   - Application type: Web application
   - Authorized JavaScript origins:
     * http://localhost:5173 (untuk testing dev)
     * https://scan-retur.vercel.app (URL domain Vercel Anda)
   - Salin Client ID yang muncul (contoh: xxxxx-xxxxx.apps.googleusercontent.com)

4) Buat file .env di root project (bukan .env.example):
   VITE_APPS_SCRIPT_URL=https://script.google.com/macros/s/PASTE_URL_DISINI/exec
   VITE_GOOGLE_CLIENT_ID=PASTE_CLIENT_ID_GOOGLE_DISINI.apps.googleusercontent.com
   ⚠️ PENTING: Jangan pernah commit file .env ke Git repository!

5) Jalankan aplikasi:
   npm run dev        <- untuk development
   npm run build      <- untuk build production (deploy ke Vercel)

6) Deploy ke Vercel:
   - Pastikan set VITE_APPS_SCRIPT_URL dan VITE_GOOGLE_CLIENT_ID di Vercel > Settings > Environment Variables
   - Push ke GitHub / drag-drop folder dist ke vercel.com

7) Install sebagai PWA di HP:
   - Buka URL aplikasi di Chrome (Android) atau Safari (iOS)
   - Android: menu titik tiga > "Add to Home screen"
   - iOS: tombol Share > "Add to Home Screen"

===========================
STRUKTUR KOLOM GOOGLE SHEET
===========================

1. Sheet "Users" (Whitelist Pengguna @blpbeauty.com):
   Email | Nama Lengkap | Role | Status | Terakhir Login
   Contoh:
   bagas@blpbeauty.com | Bagas | User | Active | ...

2. Sheet "Master Product & Lots" - wajib ada kolom:
   barcode | SKU | Product | Lots | Exp Date

3. Sheet Retur (misal "Bagas" / "Dimas") - wajib ada kolom:
   Receive Date | Distri/Event | Product | Barcode | Batch | Exp Date | Qty | Keterangan | PIC
